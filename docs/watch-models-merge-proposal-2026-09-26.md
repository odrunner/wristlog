# Watch model merges — proposal for review · 2026-09-26

**What this does:** folds duplicate model pages into one, using the same Merge as Admin → Models. Each merge moves the watches, wishlist rows, name aliases and fun facts to the target and leaves the old model as a tombstone. Members' own watch names are not touched.

**Effect (simulated on live data):** 1,068 → 856 models in use; one-owner models 944 → 688; models with 3+ owners 62 → 85; watches whose page has 3+ owners **471 → 677 (30% → 44%)**. 247 merges move 225 owners' watches and 25 wishlist rows.

**Merged:** spelling / typos, bare reference numbers, sizes, colourways, dial nicknames (Pepsi, Hulk, Smurf, Starbucks…), limited editions, colour typed into the brand field, MoonSwatch missions.

**Kept separate on purpose:** lines the maker sells under their own name (Black Bay 58 / GMT / Pro / Chrono, Seamaster 300 / Aqua Terra / Planet Ocean / Diver 300M, Royal Oak Offshore / Offshore Diver, Explorer / Explorer II, Datejust / Day-Date, Submariner / Submariner Date, Air-King), complication variants with their own name (Aquanaut Travel Time, Nautilus Perpetual, Superocean Chronograph), and **anything with a different movement type** — a quartz or solar watch never joins a mechanical family, because it would distort the accuracy strip (e.g. Khaki Field Quartz, Oysterquartz, Bambino Solar, Tissot PRX quartz vs Powermatic).
